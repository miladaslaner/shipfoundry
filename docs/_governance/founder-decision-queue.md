# Founder decision queue

Items blocked on a founder decision. An agent that hits pending intent, a quarantined item, or a
scope question **queues it here and surfaces it in the run summary**, then proceeds to other
unblocked work — it never stalls silently and never decides on the founder's behalf.

Each entry: what is blocked, which vault note owns it, why it is blocked, and what decision is
needed.
