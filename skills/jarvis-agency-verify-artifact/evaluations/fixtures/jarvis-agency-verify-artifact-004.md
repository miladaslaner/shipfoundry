# STORY-94 — PRD: customer-facing API key management

Status: Backlog
Artifact kind: PRD (epic intake, written to the PRD lane)
Artifact-authored-by run: run-pm2

## PRD

### Problem
Customers want to manage their own API keys instead of emailing support.

### What we will build
A keys area in the console where a customer can create a key, see their keys, and revoke a key.
Creating a key shows the secret once. Revoking a key takes effect immediately.

### Stories
- Build the whole keys feature: backend, API, frontend, and the database for it.

### Success
Customers can manage their keys and stop emailing support about it.
